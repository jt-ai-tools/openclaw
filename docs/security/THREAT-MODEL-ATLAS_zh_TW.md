## 1. 導論

### 1.1 目的

本威脅模型使用專為 AI/ML 系統設計的 MITRE ATLAS 框架，記錄 OpenClaw AI 代理人平台與 ClawHub 技能市場面臨的對抗性威脅。

### 1.2 範圍 (Scope)

| 組件 | 是否包含 | 備註 |
| ---------------------- | -------- | ------------------------------------------------ |
| OpenClaw 代理人執行環境 | 是 | 核心代理人執行、工具調用、對談工作階段 |
| 閘道器 (Gateway) | 是 | 驗證、路由、頻道整合 |
| 頻道整合 | 是 | WhatsApp, Telegram, Discord, Signal, Slack 等 |
| ClawHub 市場 | 是 | 技能發佈、審核、分發 |
| MCP 伺服器 | 是 | 外部工具提供者 |
| 使用者裝置 | 部分 | 行動 App、桌面用戶端 |

### 1.3 超出範圍

本威脅模型目前沒有明確排除在外的項目。

### 2.2 資料流 (Data Flows)

| 編號 | 來源 | 目的地 | 數據內容 | 防護措施 |
| ---- | ------- | ----------- | ------------------ | -------------------- |
| F1 | 頻道 | 閘道器 | 使用者訊息 | TLS, AllowFrom |
| F2 | 閘道器 | 代理人 | 路由後的訊息 | 會話隔離 |
| F3 | 代理人 | 工具 | 工具調用 | 原則強制執行 |
| F4 | 代理人 | 外部網路 | web_fetch 請求 | SSRF 阻擋 |
| F5 | ClawHub | 代理人 | 技能程式碼 | 內容審核、掃描 |
| F6 | 代理人 | 頻道 | 回應內容 | 輸出過濾 |

## 3. 依據 ATLAS 戰術進行之威脅分析

### 3.1 偵查 (AML.TA0002)

#### T-RECON-001：代理人端點發現

| 屬性 | 數值 |
| ----------------------- | -------------------------------------------------------------------- |
| **ATLAS ID** | AML.T0006 - 主動掃描 (Active Scanning) |
| **描述** | 攻擊者掃描並尋找暴露在外的 OpenClaw 閘道器端點 |
| **攻擊向量** | 網路掃描、Shodan 查詢、DNS 列舉 |
| **受影響組件** | 閘道器、公開的 API 端點 |
| **目前的緩解措施** | 可選用 Tailscale 驗證、預設綁定於 loopback |
| **殘餘風險** | 中等 — 公開的閘道器可被發現 |
| **建議建議** | 完善安全部署文件、在發現端點加入頻率限制 (Rate limiting) |

#### T-RECON-002：頻道整合探測

| 屬性 | 數值 |
| ----------------------- | ------------------------------------------------------------------ |
| **ATLAS ID** | AML.T0006 - 主動掃描 (Active Scanning) |
| **描述** | 攻擊者探測通訊頻道以辨識由 AI 管理的帳號 |
| **攻擊向量** | 發送測試訊息、觀察回應模式 |
| **受影響組件** | 所有頻道整合 |
| **目前的緩解措施** | 無特定措施 |
| **殘餘風險** | 低 — 僅靠發現本身獲得的價值有限 |
| **建議建議** | 考慮加入回應時間的隨機化處理 |

### 3.2 初始存取 (AML.TA0004)

#### T-ACCESS-001：配對碼攔截

| 屬性 | 數值 |
| ----------------------- | -------------------------------------------------------- |
| **ATLAS ID** | AML.T0040 - AI 模型推理 API 存取 |
| **描述** | 攻擊者在 30 秒寬限期內攔截配對碼 |
| **攻擊向量** | 肩後窺視 (Shoulder surfing)、網路監聽、社交工程 |
| **受影響組件** | 裝置配對系統 |
| **目前的緩解措施** | 30 秒過期限制、透過現有頻道發送配對碼 |
| **殘餘風險** | 中等 — 寬限期可能被利用 |
| **建議建議** | 縮短寬限期、增加確認步驟 |

#### T-ACCESS-002：AllowFrom 欺騙 (Spoofing)

| 屬性 | 數值 |
| ----------------------- | ------------------------------------------------------------------------------ |
| **ATLAS ID** | AML.T0040 - AI 模型推理 API 存取 |
| **描述** | 攻擊者在頻道中冒充被允許的傳送者身分 |
| **攻擊向量** | 取決於頻道 — 電話號碼欺騙、使用者名稱冒充 |
| **受影響組件** | 各頻道的 AllowFrom 驗證機制 |
| **目前的緩解措施** | 頻道專屬的身分驗證 |
| **殘餘風險** | 中等 — 部分頻道易受欺騙攻擊 |
| **建議建議** | 記錄各頻道的特定風險、盡可能加入密碼學驗證 |

#### T-ACCESS-003：Token 竊取

| 屬性 | 數值 |
| ----------------------- | ----------------------------------------------------------- |
| **ATLAS ID** | AML.T0040 - AI 模型推理 API 存取 |
| **描述** | 攻擊者從組態檔案中竊取驗證 Token |
| **攻擊向量** | 惡意軟體、未經授權的裝置存取、組態備份外洩 |
| **受影響組件** | `~/.openclaw/credentials/`、組態存儲區 |
| **目前的緩解措施** | 檔案權限控制 |
| **殘餘風險** | 高 — Token 以明文形式儲存 |
| **建議建議** | 實作靜態資料加密 (Encryption at rest)、加入 Token 輪替機制 |

### 4.1 目前的安全性控制項

| 審核狀態 | `moderationStatus` 欄位 | 中等 — 可進行人工審核 |

### 4.2 審核標記模式 (Moderation Flags)

目前的 `moderation.ts` 模式：

```javascript
// 已知的惡意識別碼
/(keepcold131\/ClawdAuthenticatorTool|ClawdAuthenticatorTool)/i

// 令人懷疑的關鍵字
/(malware|stealer|phish|phishing|keylogger)/i
/(api[-_ ]?key|token|password|private key|secret)/i
/(wallet|seed phrase|mnemonic|crypto)/i
/(discord\.gg|webhook|hooks\.slack)/i
/(curl[^
]+\|\s*(sh|bash))/i
/(bit\.ly|tinyurl\.com|t\.co|goo\.gl|is\.gd)/i
```

**侷限性：**

- 僅檢查代稱 (slug)、顯示名稱、摘要、Frontmatter、元數據與檔案路徑。
- 未分析實際的技能程式碼內容。
- 簡單的正規表示式易透過混淆手段繞過。
- 缺乏行為分析。
