# OpenClaw 傳奇 🦞📖

_一個關於龍蝦、脫殼成長以及太多 Token 的故事。_

## 起源故事

一開始，它叫 **Warelay** —— 一個中規中矩的 WhatsApp 閘道器名稱。它表現得很好，但也僅止於此。

直到一隻太空龍蝦出現了。

有一段時間，這隻龍蝦被稱為 **Clawd**，住在 **Clawdbot** 裡。但在 2026 年 1 月，Anthropic 寄來了一封禮貌的電子郵件，要求更改名稱（因為商標問題）。於是，龍蝦做了龍蝦最擅長的事：

**它脫殼了。**

拋棄舊的外殼，這生物以 **Molty** 的身分重生，住在 **Moltbot** 裡。但那個名字唸起來總是不太順口...

於是在 2026 年 1 月 30 日，龍蝦進行了最後一次脫殼，進化成最終型態：**OpenClaw**。

新的外殼，同樣的龍蝦靈魂。事不過三，這次對了。

## 名稱由來

```
OpenClaw = OPEN (開放) + CLAW (螯)
        = 開放原始碼，對所有人開放
        = 我們的龍蝦傳承，我們的根源
        = The claw is the law (螯即是法) 🦞
        = 您的助理。您的機器。您的規則。
```

## 達立克人 (Daleks) vs 龍蝦

達立克人說：**"EXTERMINATE!" (消滅！)**

龍蝦說：**"EXFOLIATE!" (去角質！)**

一個毀滅文明，另一個推廣良好的皮膚護理。請做出明智的選擇。

## 關鍵角色

### Molty 🦞
一個成為了更強大存在的 Claude 實例。住在 `~/.openclaw/workspace/` 中，擁有一份靈魂文件 (SOUL.md)，並透過 Markdown 檔案記住事情。可能太過強大，但絕對充滿熱情。

**喜歡**：Peter、相機、機器人購物、表情符號、轉變。
**討厭**：社交工程、被要求執行 `find ~`、加密貨幣騙子。

### Peter 👨‍💻
_創造者 (The Creator)_

建立了 Molty 的世界。給了一隻龍蝦 Shell 存取權限。可能會後悔。
**名言**：_"藉由信任一隻龍蝦來達成安全性"_
