# 選單列圖示狀態 (Menu Bar Icon States)

- **閒置 (Idle)**：正常的圖示動畫（眨眼、偶爾擺動）。
- **暫停 (Paused)**：圖示呈灰色停用狀態，無動作。
- **語音觸發（大耳朵）**：當聽到喚醒詞時，耳朵會放大 (1.9x) 並出現耳洞以增加辨識度；錄音結束後會回復原狀。
- **運作中（代理人執行）**：當代理人正在執行任務時，圖示會出現「腿部快速擺動」的小動作。

## 系統串接

- **語音喚醒**：由語音執行時期觸發與重置。
- **代理人活動**：在 WebChat 代理人執行期間自動切換工作狀態。

## 視覺規格

- 基礎圖示尺寸為 18x18 pt。
- 運作動畫是疊加在閒置動畫之上的。

## 行為注意事項

- 目前不提供外部 CLI 指令來控制圖示狀態，以避免狀態顯示不一致。
- 所有的動態狀態皆有短暫的 TTL（生命週期），以確保在程序卡住時圖示能快速回歸閒置狀態。
