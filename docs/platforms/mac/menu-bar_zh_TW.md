# 選單列狀態邏輯 (Menu Bar Status Logic)

## 顯示內容

- 我們在選單列圖示以及選單的第一個狀態列中呈現代理人的目前工作狀態。
- 當工作進行時，健康狀態 (Health status) 會被隱藏；直到所有工作階段皆閒置時才會重新顯示。
- 選單中的「Nodes」區塊僅列出 **裝置**（透過 `node.list` 已配對的節點）。
- 當模型提供者的用量快照可用時，「Usage」區塊會出現在 Context 下方。

## 狀態模型

- **工作階段優先順序**：`main` (主工作階段) 永遠優先顯示。若 `main` 閒置，則顯示最近一次活動的非主工作階段。我們不會在活動中途隨意切換；僅在目前工作階段轉為閒置或 `main` 變為活動狀態時才切換。
- **活動類別**：
  - `job`：高階指令執行（開始、串流中、完成、錯誤）。
  - `tool`：工具執行階段（開始、結果）。

## 圖示狀態 (IconState)

- `idle`：閒置，顯示一般的小動物圖示。
- `workingMain`：主工作階段運作中，顯示圖示標記 (Badge) 並有「腿部工作」動畫。
- `workingOther`：其它工作階段運作中，顏色較淡，無腿部動畫。

### 活動圖示映射
- `exec` → 💻
- `read` → 📄
- `write` → ✍️
- `edit` → 📝
- 預設 → 🛠️

## 選單狀態列文字

- 工作進行時：`<工作階段角色> · <活動標籤>`。
  - 範例：`Main · exec: pnpm test`。
- 閒置時：回退至顯示健康摘要。

## 偵錯覆寫 (Debug override)

- 設定 ▸ Debug ▸ 「Icon override」選擇器：可手動強制設定圖示狀態（系統自動、主工作、其它、閒置）。
