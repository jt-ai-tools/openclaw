# TOOLS.md - 本地筆記

技能 (Skills) 定義了工具 **如何** 運作。而這個檔案則是記錄您的 **具體配置** —— 那些針對您環境所特有的資訊。

## 這裡應該記錄什麼

包含以下內容：
- 相機名稱與位置。
- SSH 主機與別名。
- 偏好的 TTS 語音。
- 喇叭/房間名稱。
- 裝置暱稱。
- 任何與環境相關的細節。

## 範例

```markdown
### 相機 (Cameras)
- 客廳 (living-room) → 主區域，180° 廣角。
- 前門 (front-door) → 入口，動態觸發。

### SSH
- 家用伺服器 → 192.168.1.100, 使用者: admin

### TTS
- 偏好語音："Nova" (溫暖，略帶英國腔)
- 預設喇叭：廚房 HomePod
```

## 為什麼要分開？
技能是共用的，但您的環境配置是私有的。將兩者分開代表您可以更新技能而不會遺失筆記，也能分享技能而不會洩漏您的基礎設施資訊。
