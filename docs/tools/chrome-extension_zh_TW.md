# Chrome 擴充功能 (瀏覽器中繼)

OpenClaw Chrome 擴充功能讓代理人可以控制您 **現有的 Chrome 分頁**（即您平常使用的 Chrome 視窗），而非啟動一個獨立的受控設定檔。

接管與斷開連線僅需透過 **單一 Chrome 工具列按鈕** 即可完成。

## 概念說明

此系統由三個部分組成：
- **瀏覽器控制服務** (閘道器或節點)：代理人/工具呼叫的 API。
- **本地中繼伺服器** (環回 CDP)：連接控制伺服器與擴充功能的中間橋樑（預設為 `http://127.0.0.1:18792`）。
- **Chrome MV3 擴充功能**：使用 `chrome.debugger` 附加至活動分頁，並將 CDP 訊息傳送至中繼器。

## 安裝與載入

1. 將擴充功能安裝至穩定的本地路徑：
```bash
openclaw browser extension install
```

2. 列印安裝目錄路徑：
```bash
openclaw browser extension path
```

3. 開啟 Chrome → `chrome://extensions`：
- 啟用「開發者模式」。
- 點擊「載入解壓縮擴充功能」 → 選擇上方印出的目錄。

4. 釘選該擴充功能。

## 使用方式

OpenClaw 隨附一個內建的瀏覽器設定檔 `chrome`，預設指向該中繼器。

- **CLI**：`openclaw browser --browser-profile chrome tabs`
- **代理人工具**：呼叫 `browser` 工具時指定 `profile="chrome"`。

## 附加與斷開 (工具列按鈕)

- 開啟您想要讓 OpenClaw 控制的分頁。
- 點擊擴充功能圖示。附加成功後，圖示上會顯示 `ON` 標記。
- 再次點擊即可斷開連線。

## 遠端閘道器 (使用節點主機)

如果您的閘道器執行於另一台機器，請在執行 Chrome 的機器上啟動一個 **節點主機 (node host)**。閘道器會透過該節點代理瀏覽器動作；擴充功能與中繼器則維持在本地機器執行。

## 沙箱化工作階段

若代理人工作階段處於沙箱中，`browser` 工具可能預設使用「沙箱瀏覽器」。接管主機 Chrome 分頁需要控制 **主機** 端的瀏覽器服務。

建議做法：從 **非沙箱化** 的工作階段/代理人中使用此擴充功能。

## 安全性影響（請務必閱讀）

此功能非常強大但也具備風險。請將其視為讓模型「親手操作您的瀏覽器」。

- 擴充功能使用 Chrome 的除錯 API (`chrome.debugger`)。一旦附加，模型可以：
  - 在該分頁進行點擊、輸入或導覽。
  - 讀取頁面內容。
  - 存取該分頁已登入工作階段可存取的任何內容。
- **這不具備隔離性**：如果您附加至日常使用的帳號分頁，即代表授予了存取該帳號狀態的權限。

建議：優先為擴充功能中繼使用一個專用的 Chrome 設定檔（與您個人瀏覽資料分開）。
