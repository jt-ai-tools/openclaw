# 子代理人 (Sub-Agents)

子代理人讓您可以在不阻塞主對話的情況下執行背景任務。當您啟動一個子代理人時，它會在自己隔離的工作階段中執行、完成工作，並在結束時將結果宣告回對話中。

**使用情境：**
- 在主代理人繼續回答問題的同時，讓子代理人研究特定主題。
- 並行執行多個耗時任務（網頁抓取、程式碼分析、檔案處理）。
- 在多代理人設定中，將任務委派給專門的代理人。

## 快速開始

使用子代理人最簡單的方式是自然地對代理人下令：
> 「啟動一個子代理人來研究最新的 Node.js 版本說明」

代理人會在幕後呼叫 `sessions_spawn` 工具。當子代理人完成時，它會將發現的結果宣告回您的聊天視窗。

您也可以明確指定選項：
> 「啟動一個子代理人來分析今天的伺服器日誌。使用 gpt-5.2 並設定 5 分鐘逾時。」

## 工作原理

1. **主代理人啟動**：主代理人呼叫 `sessions_spawn` 並帶入任務描述。此呼叫是 **非阻塞的** —— 主代理人會立即收到「已接受」的狀態。
2. **子代理人背景執行**：在專用的 `subagent` 佇列通道上建立一個新的隔離工作階段。
3. **宣告結果**：子代理人完成後，會將結果宣告回發起請求的對話中。主代理人會貼出一個自然語言摘要。
4. **自動封存**：子代理人工作階段在 60 分鐘後（可自訂）會自動封存。

<Tip>
每個子代理人都有其 **獨立的** 上下文與 Token 用量。建議為子代理人設定較廉價的模型以節省成本。
</Tip>

## 組態設定

子代理人無需任何設定即可使用。預設值如下：
- 模型：目標代理人的預設模型。
- 並行上限：8 個。
- 自動封存：60 分鐘後。

### 設定預設模型
為子代理人設定廉價模型：

```json5
{
  agents: {
    defaults: {
      subagents: {
        model: "minimax/MiniMax-M2.5",
      },
    },
  },
}
```

### 設定預設推理等級 (Thinking Level)

```json5
{
  agents: {
    defaults: {
      subagents: {
        thinking: "low",
      },
    },
  },
}
```

## `sessions_spawn` 工具

這是代理人用來建立子代理人的工具。

### 參數說明
- `task` (必填)：子代理人應執行的任務內容。
- `label`：用於識別的簡短標籤。
- `agentId`：在不同的代理人 ID 下啟動（必須符合權限）。
- `model` (選填)：覆寫此子代理人的模型。
- `thinking` (選填)：覆寫推理等級（如 `off`, `low`, `medium` 等）。
- `runTimeoutSeconds`：在 N 秒後中止子代理人。
- `cleanup`：`"delete"` 或 `"keep"`。`"delete"` 會在宣告後立即封存。

## 管理子代理人 (`/subagents`)

使用 `/subagents` 斜線指令來檢查並控制當前工作階段的子代理人執行狀況：

| 指令 | 說明 |
| --- | --- |
| `/subagents list` | 列出所有子代理人執行狀況（活動中與已完成） |
| `/subagents stop <id>` | 停止正在執行的子代理人 |
| `/subagents log <id>` | 查看子代理人的對話逐字稿 |
| `/subagents send <id> <訊息>` | 發送訊息給正在執行的子代理人 |

## 宣告機制 (結果回傳方式)

當子代理人完成時，會經過 **宣告 (Announce)** 步驟：
1. 擷取子代理人的最終回覆。
2. 向主代理人的工作階段發送一則包含結果、狀態與統計數據的摘要訊息。
3. 主代理人向您的聊天視窗貼出自然語言摘要。

宣告訊息會保留執行緒/主題路由（如 Slack 執行緒、Telegram 主題）。

## 工具策略 (Tool Policy)

預設情況下，子代理人可使用 **除了** 以下工具外的所有工具（為了安全性或背景任務的不必要性）：
- 工作階段管理工具 (`sessions_list`, `sessions_history` 等)。
- 系統管理工具 (`gateway`, `agents_list`)。
- 知識獲取工具 (`memory_search`) —— 建議直接在啟動提示詞中提供相關資訊。

您可以進一步限制子代理人的工具：

```json5
{
  tools: {
    subagents: {
      tools: {
        deny: ["browser"], // 子代理人不可使用瀏覽器
      },
    },
  },
}
```

## 限制說明

- **盡力而為的宣告**：若閘道器重啟，待處理的宣告工作將遺失。
- **不支援巢狀啟動**：子代理人無法啟動自己的子代理人。
- **共用資源**：子代理人共用閘道器程序；請使用 `maxConcurrent` 作為安全閥。
- **自動封存為盡力而為**：重啟時會遺失待處理的封存定時器。
