# 推理等級 (/think 指令)

## 功能說明

- **內嵌指令**：在任何傳入訊息中加入 `/t <等級>`, `/think:<等級>` 或 `/thinking <等級>`。
- **等級 (別名)**：`off` | `minimal` | `low` | `medium` | `high` | `xhigh` (僅限 GPT-5.2 與 Codex 模型)。
  - `minimal` → 「思考」。
  - `low` → 「努力思考」。
  - `medium` → 「竭力思考」。
  - `high` → 「極限思考」（消耗最大預算）。
- **提供者注意事項**：Z.AI (`zai/*`) 僅支援開關模式 (`on`/`off`)。任何非 `off` 的等級皆視為 `on`。

## 解析優先順序

1. 訊息中的 **內嵌指令**（僅適用於該則訊息）。
2. **工作階段覆寫**（透過發送僅含指令的訊息來設定）。
3. **全域預設值**（組態中的 `agents.defaults.thinkingDefault`）。
4. **備援方案**：具備推理能力的模型預設為 `low`，其它模型為 `off`。

## 設定工作階段預設值

- 發送一則 **僅包含** 指令的訊息，例如 `/think:medium`。
- 該設定會持續作用於目前的工作階段（預設為按傳送者區分）。
- 發送不帶參數的 `/think` 可查看目前的推理等級。

## 詳細程度指令 (/verbose 或 /v)

- 等級：`on` (精簡) | `full` (完整) | `off` (預設)。
- 當 `verbose` 為 `on` 時，代理人會將每個工具呼叫作為獨立的元數據訊息發送回頻道，前綴為 `<emoji> <工具名稱>: <參數>`。這些摘要會在工具啟動時立即發送（獨立訊息泡泡）。
- 當為 `full` 時，工具執行後的輸出內容也會被轉發（獨立訊息泡泡，會截斷至安全長度）。

## 推理內容可見性 (/reasoning)

- 等級：`on | off | stream`。
- 控制是否在回覆中顯示思考區塊。
- 啟用後，推理內容會以 **獨立訊息** 形式發送，前綴為 `Reasoning:`。
- `stream` (僅限 Telegram)：在產生回覆期間將推理內容串流至草稿泡泡中，最終僅發送答案而不含推理內容。
