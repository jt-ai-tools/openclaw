# `openclaw uninstall`

移除閘道器服務與本地數據（CLI 工具本身將會保留）。

```bash
openclaw uninstall
openclaw uninstall --all --yes (移除所有內容且無需確認)
openclaw uninstall --dry-run (模擬執行)
```
