# `openclaw pairing`

核准或檢查私訊配對請求（適用於支援配對功能的通訊頻道）。

## 相關資訊：
- 配對流程說明：[配對 (Pairing)](/channels/pairing_zh_TW)

## 指令範例

```bash
openclaw pairing list whatsapp (列出請求)
openclaw pairing approve whatsapp <code> --notify (核准配對)
```
