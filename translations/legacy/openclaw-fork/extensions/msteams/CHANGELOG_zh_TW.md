# MSTeams 變更日誌 (Changelog)

> 此文件為 [English Version](CHANGELOG_zh_TW.md) 的繁體中文版本。

## 2026.1.15

### 功能特色 (Features)

- **閘道器監控**：基於 Bot Framework (Express + JWT 驗證) 的閘道器監控，具備可配置的 Webhook 路徑/連接埠與 `/api/messages` 備援方案。
- **引導設定**：針對 Azure Bot 憑證的引導設定流程（支援組態與環境變數偵測）及私訊 (DM) 策略設定。
- **頻道能力**：支援私訊、群組對談、頻道、執行緒、多媒體、投票，以及 `teams` 別名。
- **存取控制**：私訊配對/允許清單強制執行，以及具備「每團隊/每頻道」覆寫與「提及標記」門控的群組策略。
- **傳入處理**：針對聊天室/群組對談的傳入防抖 (Inbound debounce) 與歷史上下文處理；提及標籤剝離與時間戳記解析。
- **主動訊息**：透過儲存的對話參考 (Conversation references) 進行主動訊息傳送（具備 TTL/大小裁剪功能的檔案存儲）。
- **傳出訊息**：支援 Markdown 分塊的文字/多媒體發送（4k 限制）、分割/內嵌媒體處理。
- **調適型卡片 (Adaptive Card) 投票**：建置卡片、解析投票結果，並透過投票追蹤持久化投票狀態。
- **附件處理**：佔位符 + HTML 摘要、內嵌圖片擷取（包含 data: URL）。
- **媒體下載**：具備主機允許清單、驗證範圍回退，以及 Graph hostedContents/附件回退機制。
- **重試機制**：針對瞬時/限流發送失敗提供帶有退避 (Backoff) 的重試機制，並具備錯誤分類與說明。
