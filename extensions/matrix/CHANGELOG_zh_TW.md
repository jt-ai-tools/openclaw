# Matrix 變更日誌 (Changelog)

> 此文件為 [English Version](CHANGELOG.md) 的繁體中文版本。

## 2026.1.14

### 功能特色 (Features)

- **Matrix 頻道外掛程式**：支援 Homeserver + 使用者 ID 驗證（存取權杖或密碼登入，包含裝置名稱）。
- **私訊功能**：具備配對 (Pairing)、允許清單 (Allowlist)、開放或停用策略，並支援 `allowFrom`。
- **群組/聊天室控制**：允許清單策略、個別聊天室組態、提及門控 (Mention gating)、自動回覆，以及個別聊天室的技能/系統提示詞。
- **執行緒**：支援 `replyToMode` 控制與執行緒回覆（off/inbound/always）。
- **訊息功能**：文字分塊、具備大小限制的媒體上傳、回應表情 (Reactions)、投票、輸入指示器以及訊息編輯/刪除。
- **動作指令**：讀取訊息、列出/移除回應表情、釘選/取消釘選/列出釘選、成員資訊、聊天室資訊。
- **自動加入邀請**：具備允許清單支援。
- **狀態與探針**：提供健康檢查的狀態與探針報告。
