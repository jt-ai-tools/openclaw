# OpenProse 說明文件

當使用者執行 `prose help` 或詢問有關 OpenProse 的資訊時，請載入此檔案。

---

## 歡迎使用

OpenProse 是一款專為 AI 工作階段 (AI Sessions) 設計的程式語言。您可以撰寫結構化的程式來編排 AI 代理人，而虛擬機器 (VM，即目前的工作階段) 會透過啟動真實的子代理人來執行這些程式。

**一個長期執行的 AI 工作階段就是一台圖靈完備的電腦。OpenProse 則是專為其設計的程式語言。**

---

## 可用指令

| 指令 | 說明 |
| --- | --- |
| `prose help` | 顯示此說明文件 —— 引導您找到所需資訊 |
| `prose run <檔案>` | 執行一個 .prose 程式 |
| `prose compile <檔案>` | 驗證語法而不執行 |
| `prose examples` | 瀏覽並執行範例程式 |

## 常見問題 (FAQs)

### 為什麼這是一個虛擬機器 (VM)？
LLM 是模擬器 —— 當給予詳細的系統描述時，它們不只是描述它，而是模擬它。`prose.md` 規範描述了一個精確度足以誘發模擬的 VM。當模擬精度足夠時，模擬即是實作：每個工作階段啟動真實的子代理人，輸出真實的產出物，狀態持久化於對話歷史或檔案中。模擬即是執行。

### 它看起來很像 Python。
語法設計特意採用熟悉的風格 —— Python 基於縮進的結構具備高度可讀性。但其語義完全不同。OpenProse 沒有函數或類別，只有代理人、工作階段與控制流。其設計原則是：結構化但顯而易見，只需極少的文件即可達成無歧義的理解。

### 為什麼不用英文？
英語本身已經是一個代理人框架 —— 我們不是要取代它，而是要使其結構化。純英語無法區分順序與並行，無法指定重試次數，無法限定變數範圍。OpenProse 在需要模糊性（AI 判斷）的地方使用英語（位於 `**...**` 內），其餘地方則使用結構。

## 語法一覽

```prose
session "提示詞"              # 啟動子代理人
agent 名稱:                   # 定義代理人模板
let x = session "..."         # 擷取結果
parallel:                     # 並行執行
repeat N:                     # 固定次數迴圈
for x in items:               # 迭代
loop until **條件**:          # 由 AI 評估的迴圈
try: ... catch: ...           # 錯誤處理
if **條件**: ...              # 條件分支
choice **準則**: 選項         # 由 AI 選擇的分支
block 名稱(參數):             # 可重用的區塊
do 名稱(參數)                 # 呼叫區塊
```
